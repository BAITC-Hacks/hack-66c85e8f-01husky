# Kenes AI: frontend

Next.js 15 + shadcn/ui client for the meeting-protocol system. See [CLAUDE.md](./CLAUDE.md) for structure and conventions, and `../docs/superpowers/specs/` for the API contract.

```bash
pnpm install
pnpm mock      # runs fully on mocks at http://localhost:3000 (login: admin@kenes.ai, any password)
pnpm dev       # against the real backend (BACKEND_URL, default http://localhost:8000)
```
