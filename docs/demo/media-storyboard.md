# Kenes AI: сценарий медиа для README

Статус: сюжет и диалог одобрены. Запись GIF, видео и новых изображений начинается после готовности frontend и реального локального пайплайна. Сейчас подготовлен только план.

Зритель: жюри. Главный сюжет: поручение Айбека проходит от смешанной речи к проверяемому протоколу. В первой сцене зритель видит переключения языков внутри реплик; в последней открывает документ с ответственным и сроком.

## Разговор для записи

Смоделированная встреча, вымышленные участники. Дата встречи в интерфейсе: **23 сентября 2026 года**. Перед записью участники получают уведомление о записи и транскрибации ИИ.

**Серик:** «Айбек, по новому складу смета әлі дайын емес. До пятницы обнови расчёты, жеткізу шығындарын да қос. Данамен келісіп ал, чтобы договор и бюджет совпадали».

**Айбек:** «Жақсы, сметаны жұмаға дейін дайындаймын. Но от поставщика ещё нет цен. Дана, бүгін бірге қарап шығайық».

**Дана:** «Бүгін қараймыз. Договор аренды согласую с юристами до конца следующей недели».

## Результат, который проверяем перед съёмкой

| Поручение или контекст | Ответственный | Срок / отображение |
|---|---|---|
| Обновить смету и включить расходы на доставку | Айбек | 25.09.2026, «до пятницы» |
| Совместно проверить материалы по смете | Айбек и Дана | 23.09.2026, «бүгін» |
| Согласовать договор аренды с юристами | Дана | «До конца следующей недели»; дату проверяет секретарь |
| Поставщик ещё не прислал цены | Ответственный не назван | Открытый вопрос в саммари, без выдуманного срока |

Каждое поручение сохраняет дословную цитату из транскрипта. Условие про доставку должно сохраниться в сути задачи. Повторное обещание Айбека подготовить смету не должно создавать дубликат поручения.

Текущий контракт задачи содержит одного ответственного. Для совместной проверки секретарь выбирает Айбека ответственным и сохраняет участие Даны в тексте задачи. В сцене показываем эту правку; автоматическое назначение двух исполнителей не предполагается. Для конца следующей недели допустима трактовка 04.10.2026, которую секретарь проверяет перед подтверждением.

## План кадров

Длительности ниже относятся к монтажу. Время обработки измеряется при реальном прогоне.

| Материал | Кадры | Размещение |
|---|---|---|
| Главная GIF, 15–20 секунд | Открыть обработанное совещание → выделить поручение о смете → нажать цитату и показать подсвеченную реплику → показать срок 25.09 → открыть таблицу поручений в PDF | Сразу под названием и одной фразой о продукте |
| GIF «Проверка секретарём», 10–15 секунд | Открыть совместную задачу → выбрать Айбека ответственным, сохранить Дану в тексте → подтвердить протокол → показать уведомление исполнителя | Под коротким пояснением о проверке человеком |
| Видео со звуком, 60–90 секунд | Прослушать весь диалог с субтитрами и подписями спикеров → показать черновик задач → сверить доставку, цитату и даты → показать открытый вопрос о ценах → подтвердить → открыть PDF | Ссылка «Посмотреть демо» рядом с главной GIF |
| Статичный кадр | Крупно: исходная реплика, поручение о смете, Айбек, 25.09.2026. Все элементы из настоящего интерфейса | Превью видео и статичная замена GIF |

В видео оставляем естественный звук и переключения ru/kk. GIF показывает взаимодействие с интерфейсом; языковой пример зритель слышит в видео. Если ожидание обработки вырезано или ускорено, ставим соответствующую подпись и указываем фактическое время прогона.

## Передача команде

| Зона | Что нужно до записи |
|---|---|
| Frontend, Эмир | Страница совещания, читаемые реплики и поручения, переход от цитаты к сегменту, правка ответственного/срока, подтверждение, уведомления и скачивание PDF |
| Pipeline, Ардак | Реальный локальный прогон всего диалога, корректные спикеры и смешанная речь, проверяемые цитаты, сохранение доставки в поручении, отсутствие дубликата сметы |
| Backend / интеграция, Никита и агенты | Сохранение результата прогона, ручная правка, уведомление, PDF именно этого совещания; проверка даты и прав доступа |
| Автор записи после интеграции | Записать фактический интерфейс, просмотреть субтитры с носителем казахского, проверить читаемость уменьшенных кадров; затем собрать GIF и видео |

Существующие `protocol.pdf` и `protocol.docx` созданы из прежней fake-фикстуры и содержат другой разговор. Для этого сюжета нужен новый экспорт из реального прогона. Наличие макета или fake-результата не закрывает готовность к съёмке.
