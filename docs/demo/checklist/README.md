# GIF по чеклисту ТЗ

[README проекта](../../../README.md) · [Обзорные GIF и документы](../README.md)

13 пунктов обязательного и дополнительного чеклиста, плюс источники записи, саммари и напоминания. Каждому пункту соответствует отдельная GIF.

Записан настоящий frontend из `develop`, коммит [`2b12ea0`](https://github.com/BAITC-Hacks/hack-66c85e8f-01husky/commit/2b12ea09f288d567fa42489b4a3623f17ec1a7a0), на встроенных демонстрационных данных. Подпись внизу каждой GIF указывает режим и границы показа. Модели и backend в записи не запускаются. Покрытие медиа не означает приёмку ML, СЭД или on-premise.

## Повторить показ

Запустить `pnpm mock` из `frontend/`, открыть `/login?reset-mocks`, войти как `admin@kenes.ai` с любым паролем. Для сцен с протоколом используется `/meetings/101`; для дашборда `/tasks`, для эталона `/participants`, для источников `/meetings/new`. Перед отдельным сценарием сбросить mock-состояние.

В сцене СЭД протокол утверждён до начала записи. В сцене распознавания загружен WAV с тишиной, обработчик возвращает предопределённый транскрипт. Для сцены эталона Chrome запущен с `--use-fake-device-for-media-stream` и `--use-fake-ui-for-media-stream`; реальный микрофон пользователя не используется.

PNG-кадры сняты через Playwright/CDP, затем собраны FFmpeg в GIF с частотой до 10 кадров/с и палитрой 256 цветов. Gifsicle сжимает повторяющиеся кадры с сохранением пауз. Служебная кнопка Next.js скрыта; поверх записи добавлена нижняя подпись. Остальные компоненты и стили frontend не изменены.

Файлы проверены полным декодированием; конечные состояния правок проверены в mock-хранилище. Размеры, длительности и исходный коммит сохранены в [manifest.json](manifest.json).
